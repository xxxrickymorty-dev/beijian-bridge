# copy-detail.js 集成说明（匠作模式）

`prototype/copy-detail.js` 是独立经典脚本，只挂 `window.BridgeCopyDetail`，不读写 DOM，不依赖 Three.js。
形状与 `copy.js` 一致：`steps / encourage / quiz / intro / end / viewNotes`；`steps` 每一项多一个 `joint`。
**本文件不修改 `prototype/index.html`**，下面只写接线约定。

## 1. 与 copy.js 的关系

| | copy.js | copy-detail.js |
|---|---|---|
| 全局名 | `BridgeCopy` | `BridgeCopyDetail` |
| 步数 | 14 | 23 |
| step 字段 | `title / hint / knowledge / voice` | 另加 `joint`（榫卯构造一句） |
| 测验 | 3 题 | 5 题 |
| 鼓励语 | 6 条 | 8 条 |
| viewNotes | 7 键 | 8 键，多 `joint` |

`joint` 只在匠作模式显示；`copy.js` 不含该字段，两个模式可以并存加载，互不覆盖。

## 2. 加载与切换模式

放在主脚本之前、`vendor` 之后：

```html
<script src="copy.js"></script>
<script src="copy-detail.js"></script>
<script>
  // 匠作模式：优先用详细文案；否则退回 14 步
  var DETAIL = true;                          // 由 UI / 存档 / URL 决定
  var COPY = (DETAIL && window.BridgeCopyDetail) || window.BridgeCopy || null;
</script>
```

- 现有 `index.html` 里写死的是 `const COPY = window.BridgeCopy || null;`（第 288 行）。切模式时把这一行换成上面的写法即可。
- 两个模块的 `steps` 索引**不一致**（14 步 vs 23 步），**不能混用**：一旦选 `BridgeCopyDetail`，`state.step` 的 0–22 就按本文件的顺序走。
- 建议切换点：开场「开始编拱」之前，或首屏给一个「匠作模式」开关；运行中切换会导致索引错位，不做。
- 兼容回退：两个脚本都没加载时，主文件沿用原有硬编码 `hint`，不得报错（同 `specs/copy.md` 第 7 节）。

## 4. joint（节点特写）

- **数据**：每一步都带 `joint`，是一句榫卯 / 构造说明（牛头卯口、木销、半榫、别压、燕尾、将军柱锁拱、檩椽搭接、瓦口）。
- **显示**：只在匠作模式显示，位置在 `#hint` 下方、`knowledge`（「为什么」）之上或之下均可；字号比 `hint` 小一档，样式与 `knowledge` 同族，进匠作模式才渲染。非匠作模式必须不读该字段。
- **节点特写（运镜）**：不建议每步都推近镜头，只在这些索引推节点特写，其余步骤保持固定机位：

  | 索引 | 特写对象 | `joint` 关键词 |
  |---|---|---|
  | 0, 1 | 牛头卯口与木销 | 卯口 / 木销 |
  | 3 | 三节苗中节点 | 半榫 / 别压 |
  | 7 | 五节苗顶点顶横梁 | 别压 |
  | 10 | 剪刀苗交叉 | 交叉咬住 |
  | 11 | 横串与燕尾 | 燕尾 |
  | 13 | 压载后的别压点 | 别压 / 压紧 |
  | 15 | 将军柱锁拱 | 将军柱锁拱 |

- **viewNotes.joint**：点「节点特写」按钮时复用 `#toast`，3.6 秒；文案里已写明「构造为示意，不是测绘」。
- `joint` 与 `viewNotes.joint` 是两处东西：前者是每步一句，后者是按钮提示。

## 5. 小测验（多出来的两题）

- 现有测验 UI（`index.html` 第 1643–1716 行）已经按 `COPY.quiz.length` 渲染，**换文案即可，不用改 UI**：匠作模式读到 5 题，进度自动变成「1 / 5」。
- 位置不变：`finish()` 之后、结尾卡片内「三题小测验」按钮（第 261 行）旁。按钮文案建议在匠作模式改成「五题小测验」，或统一改成「知识小测验」。
- 新增两题：第 4 题考**木销算不算用钉**（榫卯 / 木销），第 5 题考**将军柱把廊屋锁在拱架上**。原 3 题顺序与答案不变。
- 计分「答对 N / 5」；全对提示沿用现有逻辑。键盘 1–4 选选项时注意：第 4、5 题是 4 个选项，与现有数字键范围一致。

## 6. 语音与鼓励语

- 朗读索引建议（节点上说，不每步说）：

  匠作模式步数多，**不要**每步朗读；`joint` 默认不朗读。
- 鼓励语 8 条：入卯成功用 `[0,1,5,7]` 轮换，放偏弹回用 `[2,3,4]`，`[6]`（别压住了）留给五节苗与压载段。

## 7. 口径与注意（与 specs/copy.md 一致）

- **步数**：任务描述写「约 30 步」，但按给定的逐项清单（牛头 2 + 三节苗 3 + 五节苗 5 + 剪刀苗 1 + 横串 1 + 拆架 1 + 压载 1 + 廊屋 9）实为 **23 步**。本文件按清单执行，未自行增补步骤。
- 北涧桥：净跨 29 米；三节苗单排 3 根、五节苗单排 5 根；真实桥是多排并列，原型做了简化，文案未把「八根」说成整座桥的全部。
- 「无钉」指无铁钉；牛头上的木销是木头，不违背这一条（第 4 题即考此点）。
- 牛头是**横向主梁**；剪刀苗**抗前后**；将军柱**把廊屋锁在拱架上**；压载**让节点更紧**——四条口径贯穿全文，勿改。
- 几何与力流均为**示意**，不是测绘；`viewNotes.force` 与 `joint` 均写明「示意 / 不是实测」。
- 未写文兴桥加钉致斜（仅相传）；未写「实时受力分析」一类说法。
- 数字用汉字（二十九米），避免合成音读错。
