# copy.js 集成说明

`prototype/copy.js` 是独立经典脚本，只挂 `window.BridgeCopy`，不读写 DOM，不依赖 Three.js。
`prototype/index.html` 未改动；下面是接线时的约定。

## 1. 加载

放在主脚本之前、`vendor` 之后：

```html
<script src="copy.js"></script>
<script>
  var C = window.BridgeCopy;   // 缺失时保留 index.html 里现有的 hint
</script>
```

## 2. 结构

| 键 | 类型 | 用途 |
|---|---|---|
| `steps` | 14 项 `{title, hint, knowledge, voice}` | 与主文件 `steps` 同序，见下表 |
| `encourage` | 6 条短句 | 入卯成功 / 放偏弹回 |
| `quiz` | 3 题 `{q, options, answer, explain}` | 合龙后 |
| `intro` | 一句 | 开场朗读 |
| `end` | 一句 | 合龙朗读 |
| `viewNotes` | `all / arch / san / wu / side / force / break` | 结构视图按钮提示 |

步骤索引（0 起）：

| 0–1 | 2–4 | 5–9 | 10 | 11 | 12 | 13 |
|---|---|---|---|---|---|---|
| 牛头 | 三节苗 | 五节苗 | 剪刀苗 | 拆架 | 压载 | 起廊屋 |

## 3. 文字放哪

- **hint**：`beginStep()` 里写进 `#hint`，替换现有 `s.hint`。保持单句，不换行。
- **knowledge**：入卯成功后（`finishPlacement()` 末尾，与 480ms 换步错开 200ms）淡入 `#hint` 下方一行「为什么 · …」。
  - 换步时清空；不叠加、不弹窗。
  - 字号比 hint 小一档，颜色取 `--ink-3`，最多两行；它是补充，不是必读。
  - 默认不朗读，避免每步都念。
- **viewNotes**：点结构视图按钮时复用 `#toast`，3.6 秒；力流那条必须保留「示意」二字。

## 4. 语音什么时候说

语音默认开，一键关；只在节点上说，不是每步都说。建议朗读索引：

```
0 牛头，2 三节苗起手，5 五节苗起手，10 剪刀苗，11 拆架，12 压载，13 廊屋
```

- 每步只念一次，重复进入不重念。
- 开头 `intro` 在点「开始编拱」后 400ms 说；结尾 `end` 在 `finish()` 后说。
- 语音与木头音效错开约 200ms，别叠在一起；`state.sound === false` 时全部跳过。
- 文字始终先于语音可见；语音失败不影响流程。

## 5. 鼓励语

- 入卯成功：从 `encourage[0..1]`、`[5]` 里轮换，不连续重复同一条。
- 放偏弹回：用 `[2..4]`，每两次失手最多一条，不做失败音效。
- CTA 步骤（剪刀苗 / 拆架 / 压载 / 廊屋）不放「入卯」类措辞，用各自的 hint 即可。

## 6. 小测验

- 位置：`finish()` 之后、结尾卡片出现之前，或结尾卡片内「看结构」按钮旁；三题逐题显示，一次一题。
- 点选项立即判对错：对，显示 `explain` 并进入下一题；错，显示 `explain`，允许再选，不扣分、不锁死。
- 三题走完停在结尾卡片，可把「答对 3/3」写进造桥记；不显示排名、不倒计时。
- 键盘可完成（数字键 1–4 选项），与「回车入卯」不冲突（测验出现时暂停拖拽监听）。

## 7. 验收与回退

- 5 个没看过廊桥的人，3 个能答对：为什么不用钉、三节苗几根、剪刀苗管什么。三题答案都在 `quiz` 里。
- `BridgeCopy` 未加载时，主文件回退到原有硬编码 hint，页面不得报错。

## 8. 口径与注意

- 三节苗三根、五节苗五根是**单排**；真实北涧桥是多排并列，原型做了简化。文案里没有把「八根」说成整座桥的全部。
- 「无钉」指无铁钉；牛头上有木销，木销是木头，不违背这一条。
- 几何为示意，不是测绘比例；只有 `viewNotes.force` 明确写了「示意」，其余靠页面已有的 legend 说明。
- 力流仍是简化三铰拱轴力，不是有限元；文案没有「实时受力分析」一类说法。
- 文兴桥加钉致斜只是相传，未写进文案。
- 音高、字数按「念出来不拗口」控制；出现「二十九米」等数字时用汉字，避免合成音读错。
