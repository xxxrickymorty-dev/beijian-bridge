# 编梁 · 北涧桥 — 交互原型

验证「三节苗 + 五节苗」这套编木拱能不能被玩家看懂，以及拆架那一下够不够响。

## 打开

案例封面在根目录 `index.html`；这里是可交互的造桥体验，直接双击 `prototype/index.html`。所有依赖都在 `vendor/`，不需要联网或构建。

如果浏览器限制本地文件，起一个静态服务：

```
cd prototype
python -m http.server 8765
```

然后访问 http://localhost:8765

## 操作

- 拖动发光的木料，靠近红色线框后松手，入卯。
- 按 `Enter` 或点「自动入卯」可以把当前木料放进卯口。
- 鼠标左键拖动旋转视角，滚轮缩放（最近可凑到 8 m 看节点）。拆架后会自动慢转。
- 右上角可以关声音。
- **节点图鉴**：右上角「节点图鉴」打开独立窗口，六种接合方式（牛头承插 / 搭接穿销 / 别压半榫 / 骑搭节点 / 平苗叠压 / 柱脚暗榫）各配一段装配动画，可拖动旋转、拖进度条逐帧看、重播；←/→ 切式，`R` 重播，`Esc` 关闭。

## 尺寸与构件

51.87 × 5.39 m，净跨 29 m，20 间廊屋，84 根桥柱（21 榀 × 4 柱），东西石阶 16 / 26 级。拱架按实测矢高 4.90 m 重建（三节苗上弦面 = 桥面 − 0.22 m），五节苗骑搭/托底关系与六种接合节点都有可读构造；具体口径见 `specs/precision-layout.md` 与 `HANDOFF.md`。

高精度模块：`precision-materials.js`（程序化 PBR 木/石/瓦）、`precision-roof.js`（实体瓦垄、脊梁、脊端）、`specs/precision-layout.md`（对照实测图的 8 步重构清单）。

## 两种模式

- **速览**：14 步，从牛头到整座廊屋，一次起屋。
- **匠作**：23 步，榫卯节点特写、横串、将军柱、立柱、上梁、架檩、铺椽、盖瓦、楼阁，廊屋一根一根立起来。

开头两个按钮选模式；详细模式里每一步会切到节点特写。

## 流程（速览 14 步 / 匠作 23 步）

左牛头 → 右牛头 → 三节苗 ×3 → 五节苗 ×5 → 剪刀苗 → 拆架 → 压载 → 起廊屋。

拆架前，拱靠四根临时支架撑着。拆架后桥体微沉，压载时力流出现；最后起廊屋，桥面、廊柱和瓦顶把拱锁成一座完整的桥。

## 调试参数

- `?built=1` 直接看整座桥的静态结构，跳过交互。
- `?auto=1` 跳过开场，直接开始。

## 结构视图

合龙后点「看结构」，右下角可以切换：

- 全部：整座桥。
- 拱架：藏掉廊屋，只看拱。
- 三节苗：只看第一系统，三根。
- 五节苗：只看第二系统，五根。
- 侧视：切到正面立面，再点一次复位。
- 力流：按简化三铰拱轴力模型给构件上色，朱砂越深压力越大。
- 抽一根：抽掉左起第二根五节苗，五节苗断开、桥体下沉；再点一次复位。

这是目前最直接讲清「两套系统」的入口。木材纹理、牛头卯口/木销、别压节点和拆架尘土也加上了。

## 声音与语音

右上角两个开关：`声音` 控制音乐、音效和语音的总静音；`语音` 单独控制中文朗读。声音是程序合成的，没有外部音频文件；语音用浏览器的 `speechSynthesis`。第一次点击「开始编拱」后才出声。

## 知识小测验

合龙后，结尾卡片上有「小测验」：速览 3 题、匠作 5 题（加木销与将军柱）。答错可以重试，不扣分。

## 范围

拱架 + 四柱九檩廊屋（曲面瓦顶、中央重檐楼阁、四角桥头屋、东 16 / 西 26 级石阶、溪岸与树）；廊屋内部陈设与雨未做。几何为示意，不是测绘比例；`PLAN.md` 里写了需要向文博馆 / 传承人核对的清单。力流用简化三铰拱轴力模型，不是有限元；粒子只是把方向演出来。
